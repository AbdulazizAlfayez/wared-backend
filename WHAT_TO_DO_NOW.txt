STEP 1: Create the Database
═══════════════════════════════════════════════════════════════

Open your terminal and run these commands:

export PATH="/opt/homebrew/opt/postgresql@15/bin:$PATH"
psql postgres -c "CREATE DATABASE car_marketplace;"

What this does: Creates an empty database for your project.

═══════════════════════════════════════════════════════════════

STEP 2: Setup and Start Server
═══════════════════════════════════════════════════════════════

Still in terminal, run these commands (one at a time):

python3 manage.py makemigrations
python3 manage.py migrate
python3 manage.py runserver

What this does:
- makemigrations: Prepares database changes
- migrate: Creates tables in database
- runserver: Starts your backend!

═══════════════════════════════════════════════════════════════

STEP 3: Test if It Works! ✅
═══════════════════════════════════════════════════════════════

1. Open your web browser
2. Go to: http://localhost:8000/api/cars/
3. You should see a webpage with: {"count": 0, "results": []}

IF YOU SEE THIS → ✅ YOUR BACKEND IS WORKING!
